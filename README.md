# traffic-signal-html-css

This is a simple Traffic Signal project created using HTML and External CSS.

## Technologies Used

- HTML
- CSS

## Project Description

This project demonstrates a basic traffic signal design using HTML elements and external CSS styling. The traffic signal contains three lights: Red, Yellow, and Green, along with a pole.

## Project Structure

traffic-signal-html-css/
│
├── index.html
├── signal.css
└── README.md

## Features

- Simple traffic signal design
- Three colored signal lights
- External CSS used for styling
- Clean and beginner-friendly HTML structure
